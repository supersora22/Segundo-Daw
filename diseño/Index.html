Tabla 6.1: ejemplos de las etiquetas de contenido incrustado.

1. Etiqueta iframe

La etiqueta iframe permite mostrar contenido de otra página web dentro de la nuestra, como un vídeo de YouTube o un mapa.

2. Etiquetas video y source

La etiqueta video sirve para reproducir vídeos en nuestra web. La etiqueta source indica dónde está guardado el archivo y qué tipo de vídeo es.

3. Etiquetas audio y source

La etiqueta audio permite escuchar sonidos o música desde la página. Source indica el archivo de audio que se va a reproducir.

4. Etiqueta svg

La etiqueta svg permite crear dibujos mediante formas geométricas, como círculos, rectángulos y triángulos, sin necesidad de utilizar una imagen externa.
