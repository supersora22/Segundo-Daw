Apuntes, ejercicios y actividades del 2º curso del CFGS de **Desarrollo de Aplicaciones Web** (Kursaal, 2025-2027).

---

## Asignaturas

| Asignatura | Carpeta | Contenido |
|---|---|---|
| Desarrollo web en entorno cliente (DWEC) | `Desarrollo Cliente/` | JavaScript: sintaxis del lenguaje, tipos de variables, operadores, ámbitos, conversiones y mecanismos de decisión. Criterios 1.4 – 1.6 y Unidad 2. |
| Diseño de interfaces web (DIWEB) | `diseño/` | HTML y CSS: listas, tablas, esquemas semánticos y el trabajo inicial de puerto. |

> De momento solo hay material de estas dos asignaturas; el resto del 2º curso se irá añadiendo según avance.
